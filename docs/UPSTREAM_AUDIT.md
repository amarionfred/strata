## Validation and next device checks

The untouched upstream baseline at `92ac947` passes OWL and original-app JVM suites. The integrated source is checked against those suites plus new profile, wallpaper-result, terminal-lifecycle, process-stop and sandbox-refusal regressions. See [preview validation](../system/companion/VALIDATION.md) for exact final counts/artifact hashes and [installation](../system/companion/INSTALL.md).

No physical device verification occurred during this audit. Before wider distribution, test personal/work/clone app actions, profile deletion/recreation, Android 15+ private-space role/lock changes, browser shortcut pinning, locale changes, wallpaper rejection/live-wallpaper preservation, notification revocation/open/dismiss, terminal IMEs/touch, and original stop/resume while idle and after a managed package operation. Stop/resume must preserve files and prevent widget-triggered restarts. The original app's full native APK was not built here because its PRoot native libraries are absent; the distributed APK is the native preview.

The wallpaper visibility declaration is narrowly scoped: `QUERY_ALL_PACKAGES` is capped at API 33 because `getWallpaperInfo()` requires it there; Android 14+ uses the wallpaper-service `<queries>` declaration. The specific lint permission warning is suppressed with that documented reason, not by disabling lint. See [Android WallpaperManager](https://developer.android.com/reference/android/app/WallpaperManager#getWallpaperInfo()). Android 17 LAN behavior follows [Android's local-network permission guide](https://developer.android.com/privacy-and-security/local-network-permission).
